# 在线考试系统 V1.1 候选路线

以下内容是 V1 验收中明确不实施的候选项，需在后续需求评审、数据设计和安全评审后再排期：

- Excel 批量导入题目与学生
- 直接调用 AI API 出题、题库语义去重
- 随机组卷与抽题策略
- 考试统计图表、成绩 Excel 导出
- 错题本与知识点分析
- 补考、重考与多 Attempt 规则
- 防作弊、切屏检测和摄像头监考
- Markdown 安全渲染增强（引入 sanitizer 后再开放 HTML 展示）
- Redis、消息队列和异步任务（仅在明确性能需求后评估）

V1.1 不应以修改已发布考试快照、放宽 RBAC 或向学生泄露答案为代价。
