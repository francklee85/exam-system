# Markdown 题库批量导入规范

## 1. 适用范围

Markdown 导入面向 `admin` 和 `teacher`，用于将人工编写或 ChatGPT、Claude、
DeepSeek 等工具生成的标准 Markdown 题库批量写入现有 `questions` 和
`question_options`。

系统不会调用 AI API，也不会尝试猜测、修复或兼容任意 Markdown 写法。导入过程固定为：

```text
粘贴 Markdown / 上传 .md
→ 后端解析预览
→ 逐题显示合法性、行号和错误原因
→ 用户确认
→ 后端重新解析并校验
→ 合法题目创建，非法题目跳过
→ 返回导入统计
```

创建人始终来自当前 JWT 用户，导入题目的初始状态为 `active`。

## 2. 文档与题目分隔

- 文件顶部可以包含一个 `# 任意题库标题` 和普通说明。
- 每道题必须以独占一行的 `## 题目` 开始。
- `---` 可以用于视觉分隔，但不是解析依据。
- 代码块内出现的 `## 题目` 或字段标题属于代码内容，不会分割题目。
- 一次请求最大 1 MB、最多 500 道题。

## 3. 固定字段

只识别：

```text
类型：
难度：

### 题干
### 选项
### 正确答案
### 参考答案
### 解析
```

`类型：`、`难度：`必须使用中文全角冒号。`答案`、`标准答案`、`Answer`、
`正确选项`、`参考解析`等标题不会被自动猜测，会在预览中报错。

类型映射：

| Markdown | question_type | 阅卷方式 |
| --- | --- | --- |
| 单选题 | `single_choice` | 自动 |
| 多选题 | `multiple_choice` | 自动 |
| 判断题 | `true_false` | 自动 |
| 填空题 | `fill_blank` | 人工 |
| 主观问答题 | `subjective` | 人工 |

难度映射：

| Markdown | difficulty |
| --- | --- |
| 简单 | `easy` |
| 中等 | `medium` |
| 困难 | `hard` |

## 4. 五种题型示例

````markdown
# Linux 基础题库

## 题目

类型：单选题
难度：简单

### 题干

Linux 中查看当前工作目录的命令是什么？

### 选项

- A. cd
- B. pwd
- C. ls
- D. mkdir

### 正确答案

B

### 解析

`pwd` 命令用于显示当前工作目录。

---

## 题目

类型：多选题
难度：中等

### 题干

以下哪些属于 Linux 常见文件系统？

### 选项

- A. ext4
- B. XFS
- C. NTFS
- D. Btrfs

### 正确答案

A, B, D

### 解析

ext4、XFS 和 Btrfs 都属于常见文件系统。

---

## 题目

类型：判断题
难度：简单

### 题干

Kubernetes 是一个容器编排系统。

### 正确答案

正确

### 解析

Kubernetes 用于容器化应用编排。

---

## 题目

类型：填空题
难度：简单

### 题干

Linux 默认超级用户名称是 ______。

### 参考答案

root

### 解析

Linux 默认超级用户为 root。

---

## 题目

类型：主观问答题
难度：中等

### 题干

请简述 Docker 容器和传统虚拟机的主要区别。

### 参考答案

Docker 容器共享宿主机内核，传统虚拟机通常运行完整 Guest OS。
容器启动更快、资源占用通常更低。

### 解析

考查容器虚拟化和传统硬件虚拟化的区别。
````

## 5. 题型规则

### 5.1 单选题

- 必须有题干、选项、正确答案。
- 选项使用 `- A. 内容`，编码范围 A-Z，至少两个。
- 正确答案只能是一个字母；小写会转为大写。
- 禁止参考答案。

### 5.2 多选题

- 必须有题干、选项、正确答案。
- 正确答案使用英文逗号，例如 `A,B,D` 或 `A, B, D`。
- 字母会转为大写并稳定排序。
- 至少两个不同正确答案，最终仍由 Question Service 校验选项存在性与重复值。
- 禁止参考答案。

### 5.3 判断题

- 必须有题干、正确答案。
- 正确答案只能是 `正确` 或 `错误`，分别转换为 `["true"]`、`["false"]`。
- 禁止选项和参考答案。

### 5.4 填空题

- 必须有题干。
- 参考答案、解析可省略，且支持多行。
- 禁止选项和正确答案。
- 转换后 `correct_answer = NULL`，仍然永远人工阅卷。

### 5.5 主观问答题

- 必须有题干。
- 参考答案、解析可省略，且支持多行。
- 禁止选项和正确答案。
- 转换后 `correct_answer = NULL`，仍然永远人工阅卷。

## 6. Markdown 代码块

题干、选项、参考答案和解析均允许围栏代码块。解析器会保留代码块原文，并忽略代码块
内部看起来像题目标记或字段标题的行。例如：

````markdown
### 题干

以下命令的作用是什么？

```bash
kubectl get pods
```
````

选项内容也可以为多行：

````markdown
### 选项

- A.
  ```bash
  kubectl get pods
  ```
- B.
  ```bash
  kubectl delete namespace default
  ```
````

代码块必须闭合，否则预览会返回起始行和错误原因。

## 7. API

```text
POST /api/v1/questions/import/preview
POST /api/v1/questions/import
```

两个接口都使用现有 `TeacherOrAdmin` 权限和统一 Axios/JWT 认证。请求：

```json
{
  "markdown": "## 题目\n..."
}
```

预览返回总数、合法数、非法数、文档级错误，以及每道题的起止行、规范化 Payload 和
错误列表。确认接口不会信任前端预览，会重新解析并再次调用现有 Question Service
五题型校验；所有合法题目在一个数据库事务中创建，非法题目不写入。

## 8. AI 出题 Prompt 模板

```text
你是一名职业教育题库设计专家。请严格按照下列规则生成 Markdown 题库，不要输出任何格式之外的字段：

1. 每道题必须以“## 题目”开始。
2. 类型只能是：单选题、多选题、判断题、填空题、主观问答题。
3. 难度只能是：简单、中等、困难。
4. 固定字段标题只能使用：### 题干、### 选项、### 正确答案、### 参考答案、### 解析。
5. 单选题/多选题选项必须使用“- A. 内容”格式；单选答案为一个字母，多选答案用英文逗号分隔。
6. 判断题正确答案只能写“正确”或“错误”，且不能包含选项或参考答案。
7. 填空题和主观问答题不能包含选项或正确答案，可包含多行参考答案。
8. 题干、选项、参考答案和解析允许 Markdown 代码块；不要在代码块外使用其他三级标题。
9. 题目之间可以使用“---”分隔。

请围绕【在这里填写课程主题】生成【在这里填写数量】道题，覆盖所需题型和难度，并只输出最终 Markdown。
```
